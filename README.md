# 《청운강호전 (靑雲江湖傳)》 — 1993 무협 액션 RPG 웹/모바일 에디션

1993년 클래식 무협 액션 RPG의 감성과 **12챕터 장편 서사 구조**를 계승하되, **저작권 이슈가 있는 외부 이미지/음원(`sm/`, `assets/`) 없이 100% 자체 생성(Procedural) 2D 도트 그래픽과 Web Audio 5음계 신스**로 구동되는 경량 웹/PWA 액션 RPG입니다.

* **실행 환경**: 웹 브라우저, 보급형 CPU + 내장 GPU 및 스마트폰에서 안정적인 60fps 동작
* **핵심 특징**:
  * **12챕터 장편 시나리오 & 4종 멀티 엔딩**: 청운산문 입문 → 낙양 객잔 호위 → 태행산 매복 → 대나무 숲 기연 → 매화장 최종 결전(`em1~3`, `d9`)
  * **고도화된 액션 전투**: 3단계 공격 프레임(`WINDUP → ACTIVE → RECOVER`), 선입력 버퍼, **저스트 패링(`Q`)**, 포이즈 & 그로기 극딜, **경공 도약(`X`)**, 5대 무공(`1~5`), 보스 패턴 예고 장판(적색 패링 가능 / 자색 회피 전용)
  * **오프스크린 타일 캐싱 & AdLib 5음계 신스**: `TileAtlas` 1회 베이킹 + Web Audio 실시간 합성으로 외부 에셋 없이 즉시 실행 및 오프라인 PWA(`public/sw.js`) 지원

## 로컬 실행 (`Node.js v14.15.1` 호환, 포트 `5188`)
```bash
npm install
npm run build   # src/**/*.ts -> public/dist/**/*.js
npm start       # http://127.0.0.1:5188
```

## 조작법
* **이동**: `WASD` / 방향키 / 화면 터치 8방향 D-Pad
* **공격 / 패링 / 경공 / 대화**: `Space`(`J`) / `Q`(`K`) / `X` / `E`(`F1`) 또는 우하단 터치 버튼
* **무공 전환**: `1~5` (`청운검법`, `파천구검`, `영사검법`, `흡원대법`, `자하심법`)
* **저장 / 불러오기**: `F5` / `F9` (또는 우상단 `⚙ 메뉴·저장` 드로어 `SV0~SV2` · `QUICK`)
